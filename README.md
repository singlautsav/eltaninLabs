# Eltanin Labs  AI-First Talent & Technical Delivery Studio

Official landing page and interactive capability pod estimator for **Eltanin Labs** (https://www.eltaninlabs.com).

## Overview
- **AI-First Capability Pods**: Interactive talent matching engine & capability explorer.
- **Engagement Cost Estimator**: Live dynamic budget & pod composition calculator.
- **Studio Pricing**: Transparent engagement rate cards and service tiers.
- **Dark / Light Mode**: Seamless theme switching with system preference detection.
- **Mobile-First & Ultra-Responsive**: Clean responsive design tested across desktop, tablet, and mobile viewports.

## Tech Stack
- **HTML5 / CSS3**: Vanilla CSS design system with custom properties, micro-animations, glassmorphism, and responsive grids.
- **JavaScript (ES6+)**: Interactive match engine, talent filter tabs, and live pod cost calculator.
- **Deployment**: Configured for instant deployment on [Vercel](https://vercel.com).

## Local Development
To run locally:
```bash
# Using Python
python3 -m http.server 8000

# Or using Node
npx serve .
```

Visit `http://localhost:8000` in your browser.
